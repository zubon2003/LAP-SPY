# LAP-SPY

iPhoneのカメラでFPV映像を写し、スタート/ゴールゲートに貼ったArUcoマーカーの「検出→消失」をゲート通過としてラップタイムを計測するWebアプリです。マーカー検出には OpenCV.js を使います。

**開く:** https://zubon2003.github.io/LAP-SPY/ （Safariで開き、カメラを許可してください）

## 機能
- マーカー種類（4x4〜7x7, ARUCO_ORIGINAL）とマーカーIDの指定
- 最小ラップタイム：前回通過から最小ラップ未満で再通過した場合は、新ラップではなく直前ラップを上書き
- リセット後、1回目の通過から計測開始。`LAP1 12.3456` 形式で表示
- 消失判定時間（検出漏れによる誤検知防止）、解析解像度、前面/背面カメラ、表示反転、通過音
